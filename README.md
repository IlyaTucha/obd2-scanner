# OBD2 Scanner

Android-приложение для диагностики автомобиля через **ELM327 Bluetooth**-адаптер.
Подключается к OBD2-разъёму машины, показывает параметры двигателя в реальном времени,
ведёт журнал поездок с маршрутом на карте, читает и расшифровывает коды неисправностей (DTC)
и хранит профили для нескольких автомобилей.

Написано на **Kotlin + Jetpack Compose (Material 3)**, архитектура MVVM + Clean Architecture,
DI на Hilt. Интерфейс на русском языке.

## Что умеет

### Подключение
- Связь с адаптером **ELM327** по Bluetooth (RFCOMM).
- Автоматическая инициализация ELM327, согласование OBD-протокола и определение
  поддерживаемых PID-ов автомобиля.
- Автоподключение к известному адаптеру при запуске.
- Устойчивость к «призрачным» обрывам связи дешёвых клонов ELM327: двухуровневый
  сторож зависаний (мягкая переинициализация → пересоздание сокета) и автоматический
  реконнект без потери текущей поездки.

### Параметры в реальном времени
- Живые датчики: скорость, обороты, нагрузка двигателя, положение дросселя, давление
  во впуске (MAP), температура охлаждающей жидкости, напряжение и другие PID-ы.
- Многоуровневый опрос: «горячие» параметры читаются каждый цикл, «медленные» — реже,
  чтобы интерфейс не мерцал и связь не перегружалась.
- Защита от выбросов значений скорости у клонов ELM327 (фильтр физически недостижимых скачков).
- Стрелочные спидометр-индикаторы (gauges), мини-графики (sparkline) и детальные экраны
  по каждому параметру с историей.
- Расчёт мгновенного и среднего расхода топлива.

### Поездки и сессии
- **Автоматические поездки**: подключение к адаптеру открывает поездку, остановка двигателя
  ставит её на паузу (а не завершает), повторный старт продолжает ту же поездку.
- **Автопауза и автозавершение**: если после паузы 8 часов не было движения, поездка
  завершается сама. Концом поездки считается последняя запись, поэтому время стоянки
  после приезда в неё не входит.
- **Ручная пауза**: кнопка «Пауза» на вкладке «Сессия» ставит поездку на паузу без
  ограничения по времени (например, ночёвка в дороге): такая поездка не завершается сама,
  в том числе после перезапуска приложения. Запись продолжается при следующем запуске
  двигателя (в GPS-поездке — когда машина поедет) или по кнопке «Продолжить».
- Фоновая запись поездки (foreground-сервис) с GPS-треком через Google Play Services.
- Итог поездки: пройденный путь, средняя/максимальная скорость, расход, длительность
  и **маршрут на карте Яндекса**.
- **Запись по GPS без адаптера**: кнопка на вкладке «Сессия» пишет маршрут, скорость,
  пробег и время в пути по спутникам; если адаптер подключится, данные двигателя
  добавятся в ту же сессию. На долгой стоянке запись сама встаёт на паузу.
- История поездок и экспорт данных.

### Диагностика ошибок (DTC)
- Чтение сохранённых, ожидающих и постоянных кодов (Mode 03/07/0A), в том числе
  многокадровых ответов CAN и ответов нескольких блоков.
- Статус лампы Check Engine, готовность мониторов самодиагностики, стоп-кадр.
- Сброс кодов с подтверждением и проверкой ответа блока.
- Справочник около 800 кодов на русском: стандартные коды SAE J2012 с одинаковым
  смыслом на любой машине и коды производителя с пометкой, что расшифровка зависит от марки.
- Ручная расшифровка любого кода без подключения к машине.

### Профили и журнал авто
- Профили нескольких автомобилей с предустановленными пресетами.
- Декодирование VIN.
- «Авто» — журнал пробега, расходов и обслуживания с графиками трат, импортом и экспортом.

### Прочее
- Хранение данных в локальной базе **Room** с обязательными миграциями (история не теряется
  при обновлении приложения).
- Автоматический бэкап базы раз в сутки при запуске (сжатый .db.gz, хранятся последние 3 копии).
- Поддержка горизонтальной ориентации.

## Сборка и запуск

Проект собирается через **Android Studio**:

1. Откройте папку `obd2-scanner/` в Android Studio (File → Open).
2. Дождитесь синхронизации Gradle.
3. Запустите приложение на устройстве или эмуляторе кнопкой **Run** (либо соберите
   APK через Build → Build Bundle(s) / APK(s) → Build APK(s)).

Требования: **JDK 17**, `compileSdk`/`targetSdk` 34, `minSdk` 26.

### Ключ Яндекс.Карт

Карта в итоге поездки использует Yandex MapKit. Положите ключ в `local.properties`
(в репозиторий не коммитится):

```properties
YANDEX_API_KEY=ваш_ключ
```

Без ключа карта в итоге поездки будет пустой — остальное приложение собирается и работает.

## Технологии

- **Kotlin**, **Jetpack Compose**, **Material 3**
- **Hilt** — внедрение зависимостей
- **Room** — локальная база данных
- **Coroutines / Flow** — асинхронность и реактивные потоки данных
- **Yandex MapKit** — карта маршрута
- **Google Play Services Location** — GPS-трек поездки

## Архитектура

MVVM + Clean Architecture, один модуль `app`, корневой пакет `com.obd2monitor`:

- `domain/` — модели, интерфейсы репозиториев, use-case'ы;
- `data/` — реализации репозиториев, Bluetooth/ELM327, парсинг OBD, база Room;
- `ui/` — экраны Compose, переиспользуемые компоненты, тема, навигация;
- `service/` — фоновая запись поездок и управление автосессиями;
- `di/` — модули Hilt.

Конвейер опроса OBD:
`BluetoothObdConnection` → `ELM327Protocol` → `OBDParser` → `PIDRepository` → `FuelCalculator`.
